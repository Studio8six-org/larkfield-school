# Larkfield Court School: motion edition

Fictional school website concept by Studio8six, built around scroll-driven animation. Static site, no build step.

Features: percent preloader, pinned hero with rising tiles, circle-reveal menu, velocity-reactive ticker, word-by-word reveal, drawn underlines, count-ups, tile wall with lightbox, drag/arrow photo rail, hover-expand stage panels, magnetic buttons. Respects `prefers-reduced-motion`.

Run locally: `npx serve .`

All school details are fictional. Photos are from Pexels, see `PHOTO-CREDITS.md` (including the model-release note). The page carries `noindex`.
